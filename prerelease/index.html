xgems prerelease conda channel

Test builds of xGEMS with the Optima solver modes. GEMS3K (develop_optima) and Optima (optima_develop) are bundled into the xgems package. Not a release: it can change or disappear at any time.

Install

conda create -n xgems-optima --override-channels --strict-channel-priority \
  -c https://gemshub.github.io/xgems/prerelease -c conda-forge xgems
